    我们做了什么

    在原有 MATLAB App Designer 软件的基础上，保留并封装经典 Impedance_Matching.exe 计算内核，新增 Python / MATLAB R2025b 双计算引擎、MCP 标准接口、多模型工具调用智能体（OpenAI 兼容 / Anthropic）与现代化可视化界面。

    01五种拓扑解析设计 + 节点法复核
    02Smith 圆图逐步动画与匹配范围扫描
    03VSWR 带宽、±5% 容差、耐压分析
    04MCP 服务，可被 ZCode / 任意 Agent 调用
    05多模型对话、附件解析、工具调用
    06一键导出 HTML / Markdown 报告
