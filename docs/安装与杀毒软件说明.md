## 1. 一句话说明

最终发布形态是一个 **Windows 安装程序 `ImpedanceMCP_Setup_v4.3.0.exe`**：

- 复制到任意 **Windows 10/11 x64** 电脑（无需 Python、无需 MATLAB、无需 Node.js）；
- 双击安装，可修改安装目录、选择是否创建桌面快捷方式；
- 安装完成后，桌面/开始菜单快捷方式指向 `ImpedanceMCP.exe`；
- 双击 `ImpedanceMCP.exe` 即打开独立软件；
- 同一目录下的 `ImpedanceMCP_MCP.exe --mcp` 就是 MCP stdio 服务器。
- 主程序是 Windows GUI 子系统：双击只出现原生窗口，不会出现命令行或浏览器。

> 32 位 Windows（x86 OS）不支持：本程序使用 64 位 Python/NumPy 运行时。  
> 绝大多数 Windows 10/11 都是 x64（x86_64）；安装程序会检测并给出明确提示。

## 2. 安装程序会检测什么

`ImpedanceMCP_Setup_v4.3.0.exe` 在安装前/安装中检测：

| 检查项 | 处理 |
|---|---|
| Windows 版本 | 要求 Windows 10/11 x64 |
| CPU 架构 | 要求 x64；32 位系统给出提示并退出 |
| 是否已安装旧版本 | 支持覆盖升级，保留用户数据 |
| 磁盘空间 | 不足时提示 |
| Visual C++ 运行库 | 缺失时自动运行安装包内附带的 `VC_redist.x64.exe` |
| Microsoft Edge WebView2 Runtime | 缺失时自动静默安装；原生窗口需要 |
| MATLAB Runtime R2023b | 仅“原版经典界面”需要；新版不需要。安装程序会检测并提示，不会强制安装 974 MB 运行时 |
| ZCode 配置 | 勾选“为 ZCode 写入 MCP 配置”时，自动写入并备份原配置 |
| 桌面快捷方式 | 可选；另有可选“一键卸载”桌面快捷方式 |
| 开始菜单快捷方式 | 默认创建，含“一键卸载 ImpedanceMCP（清除全部数据）” |
| 帮助文档 | 安装到 `{安装目录}\docs`，开始菜单可打开 |

安装程序**不会**：

- 安装 Python / Node.js / MATLAB；
- 修改系统 PATH；
- 上传任何数据；
- 写入任何 API Key（Key 只由用户在软件设置里填写）。

## 3. 安装步骤

1. 双击 `ImpedanceMCP_Setup_v4.3.0.exe`；
2. 选择安装目录（默认 `C:\Program Files\ImpedanceMCP`，需要管理员权限；可改到 `D:\Apps\ImpedanceMCP` 等）；
3. 勾选：
   - 创建桌面快捷方式（可选）；
   - 创建开始菜单快捷方式（默认）；
   - 为 ZCode 写入 MCP 配置（可选，自动备份原 `config.json`）；
   - 安装原版经典界面（可选，需要后续 MATLAB Runtime）；
4. 安装；
5. 完成后可勾选“立即运行 ImpedanceMCP”。

安装后的目录示例：

```text
D:\Apps\ImpedanceMCP\
├─ ImpedanceMCP.exe          # 主程序：原生窗口，双击即用
├─ ImpedanceMCP_MCP.exe      # MCP 控制台：--mcp / --mcp --http 8790
├─ _internal\                # 运行时与依赖（不要删除）
├─ docs\                     # 内置帮助文档（HTML/PDF）
├─ classic\Impedance_Matching.exe  # 原版 MATLAB 经典界面（可选）
├─ unins000.exe              # 一键卸载（清除全部数据）
├─ LICENSE
└─ README.md
```

用户数据（配置、上传、报告）在：

```text
%LOCALAPPDATA%\ImpedanceMCP\
```

卸载程序在“设置 → 应用”中，开始菜单也有“一键卸载 ImpedanceMCP（清除全部数据）”。
**卸载会删除全部用户数据、MCP 条目、快捷方式和注册表项，不保留任何残留。**

## 4. 为什么“复制一个安装程序”就能用

因为安装程序内部包含：

- PyInstaller 打包的 Python 运行时；
- NumPy、Web 前端、MCP 服务器、计算内核；
- WebView2 原生窗口桥接；
- 帮助文档；
- VC++ 运行库（用于原版经典界面）；
- WebView2 Runtime 安装引导（缺失时自动安装）。

新电脑只需要：

1. 复制 `ImpedanceMCP_Setup_v4.3.0.exe`；
2. 双击安装；
3. 双击桌面快捷方式。

**不需要**：

- 安装 Python；
- 安装 MATLAB；
- 安装 Node.js；
- 配置环境变量；
- 联网（AI 对话除外）。

原版经典界面 `classic\Impedance_Matching.exe` 仍然需要 MATLAB Runtime R2023b；
新版独立软件与 MCP **不需要**。

## 5. 杀毒软件误报：现实与正确做法

### 5.1 先说结论

**没有任何“许可证”能阻止卡巴斯基/Windows Defender 误报。**  
开源许可证（MIT）只是法律授权，不是杀毒软件的白名单。

可靠的做法是：

1. **代码签名（Code Signing）**——最重要；
2. **减少可疑打包特征**——onedir、无 UPX、带版本信息；
3. **建立下载信誉**——HTTPS、GitHub Release、SHA-256、VirusTotal 多引擎报告；
4. **主动提交误报**——Microsoft、Kaspersky、VirusTotal。

### 5.2 代码签名

- 使用受信任 CA 颁发的 **Authenticode 代码签名证书**（OV 或 EV）；
- 对 **安装程序和 `ImpedanceMCP.exe`** 都签名；
- 使用时间戳服务器（RFC 3161），保证证书过期后签名仍有效；
- EV 证书通常能更快建立 SmartScreen 信誉。

示例（需要你自己的 `.pfx` 证书）：

```bat
signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 ^
  /f mycert.pfx /p <password> ImpedanceMCP.exe
signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 ^
  /f mycert.pfx /p <password> ImpedanceMCP_Setup_v4.3.0.exe
```

> 本项目仓库提供 `installer/sign_example.ps1` 模板，但**不包含证书**；没有证书就无法伪造受信任签名。

### 5.3 打包方式

- 安装包内使用 **PyInstaller onedir**，而不是 onefile 自解压；
- 不使用 UPX 压缩；
- 可执行文件带完整版本信息（CompanyName / ProductName / FileVersion / LegalCopyright）；
- 安装程序带版本信息、图标和许可证页；
- 不写启动项、不注入进程、不修改系统浏览器、不联网上传数据。

这些只能“降低”误报概率，不能保证 100%。

### 5.4 发布时附带

- `SHA256SUMS.txt`：每个附件的 SHA-256；
- VirusTotal 多引擎报告链接（上传后生成）；
- GitHub Release 的 HTTPS 下载链接；
- `LICENSE`（MIT）与 `SECURITY.md`。

### 5.5 如果被杀毒软件删除

1. 从官方 GitHub Release 重新下载；
2. 核对 `SHA256SUMS.txt`：

```bat
certutil -hashfile ImpedanceMCP_Setup_v4.3.0.exe SHA256
```

3. 在杀毒软件中查看隔离区，恢复并加入排除（仅在你确认哈希一致时）；
4. 向厂商提交误报：
   - Microsoft：<https://www.microsoft.com/en-us/wdsi/filesubmission>
   - Kaspersky：<https://opentip.kaspersky.com/>
   - VirusTotal：<https://www.virustotal.com/>
5. 不要关闭杀毒软件长期裸奔；不要把安装包来源不明的版本加入白名单。

### 5.6 关于“许可证”

- MIT License 允许使用、修改、分发；
- 它**不会**让 Windows Defender/Kaspersky 放行；
- 如果用于商业分发，建议同时提供代码签名、隐私说明和 EULA；
- 本软件不收集用户数据，API Key 仅保存在本机。

## 6. MCP 配置

安装程序勾选“为 ZCode 写入 MCP 配置”后，会自动写入：

```json
{
  "mcp": {
    "servers": {
      "impedance-matching": {
        "type": "stdio",
        "command": "D:\\Apps\\ImpedanceMCP\\ImpedanceMCP_MCP.exe",
        "args": ["--mcp"],
        "timeoutMs": 120000
      }
    }
  }
}
```

原配置会备份为 `config.json.bak_YYYYMMDD_HHMMSS`。

Claude Code / Codex / Cursor / Cherry Studio 的配置见
`docs/MCP兼容性说明.md`，或在软件「设置 → ZCode MCP 配置」中一键复制。

## 7. 两种使用模式

1. **软件内置 AI**（类似 MATLAB Copilot）：
   - 设置 → 选择服务商（214 家）→ 模型 → 自己的 API Key；
   - 在「AI 智能体」里对话，自动调用 15 个工具。

2. **外部 AI 通过 MCP 调用**（类似 MATLAB 的 MCP 连接 Codex）：
   - ZCode / Claude Code / Codex / Cursor / Cherry Studio 配置 `ImpedanceMCP_MCP.exe --mcp`；
   - 外部智能体调用设计、扫描、复核、耐压、报告等工具。

两种模式可以同时使用；不配置 AI 也能独立做全部计算。

## 8. 常见问题

**Q：安装程序需要管理员权限吗？**
A：需要管理员权限：默认安装到 `C:\Program Files`，并写入机器级卸载信息；普通用户可在 UAC 提示中确认。

**Q：安装后能移动目录吗？**
A：可以移动整个安装目录，但快捷方式会失效；建议重新运行安装程序或手动改快捷方式。MCP 配置中的路径也需要同步修改。

**Q：卸载会删除我的设计和报告吗？**
A：会。这是“一键彻底卸载”：用户数据、API Key、上传、报告、WebView2 缓存、MCP 配置、快捷方式和注册表项全部删除。如需保留，请先导出报告/备份。

**Q：为什么安装包这么大？**
A：包含 Python 运行时、NumPy、Web 前端、MCP 服务器、帮助文档；原版 MATLAB Runtime 不包含（974 MB），新版不需要。

**Q：Windows 7 能用吗？**
A：不支持；要求 Windows 10/11 x64。

**Q：32 位 Windows 能用吗？**
A：当前版本不支持 32 位 OS；需要 64 位 Windows。

**Q：杀毒软件还是报毒怎么办？**
A：先核对 SHA-256；再提交误报；长期方案是代码签名。没有签名的 PyInstaller 程序被个别引擎误报是行业常见问题，不是本软件包含恶意行为。
