快速开始

  1. 双击 ImpedanceMatchingAI.exe 打开软件。
  2. 在“设置 → 模型服务”中选择厂商、填写自己的 API Key；不配置模型也可使用全部本地计算。
  3. 在“教材库”点击“添加教材”，或把 PDF/DOCX/PPTX 放进 TextBook/。
  4. 在“文档中心”全文搜索本说明书，或使用右侧浮动 AI 边看边问。
