微波阻抗匹配计算正确性审计

版本：v4.2.0 ｜ 更新日期：2026-10-26

开发者：卢瑞林、卢柯吉、林芷伊、张昀蕾 联系：radarlurui@gmail.com ｜ Lu_Skywalker2915@sjtu.edu.cn 上海交通大学集成电路学院（信息与电子工程学院）

0. 审计结论（先看这里）

  1. 本软件的匹配设计公式，是理想无损集总参数网络在正弦稳态下的精确解；节点法与 ABCD 级联两种独立方法交叉验证，误差在 1e-8 量级。
  2. 每个设计都用完整网络节点法重新计算 Zin / VSWR / S11，不是“只套公式不验证”。
  3. 正向扫描点被逐点反算验证：扫描给出的“可匹配负载”代回网络后，VSWR < 1.001。
  4. Smith 圆图轨迹连续性、功率守恒、VSWR 与 Γ 关系均通过测试。
  5. MATLAB R2025b 独立实现与 Python 引擎 5/5 一致，Zin 偏差 0.0。
  6. 边界：这里验证的是“理想集总元件电路”的精确性；不包含 PCB 寄生、封装 ESL/ESR、自谐振、微带不连续性或全波电磁场求解。实际工程需用实测元件模型或全波仿真复核。

1. 适用范围与模型假设

本软件的“电磁场公式”是微波网络理论中的集总参数电路模型：

  • 工作频率为单一正弦稳态；
  • 元件为理想无损电感 L、理想无损电容 C；
  • 网络由串联/并联支路组成，连接线无损耗、无相移；
  • 参考阻抗 Z0 为实数（默认 50Ω）；
  • 负载为线性时不变复阻抗 Z_L = R_L + jX_L，R_L > 0；
  • 匹配目标：从源端看入的输入阻抗 Zin = Z0，等价于 Γ=0、VSWR=1。

在这个模型内，基尔霍夫电压/电流定律（KVL/KCL）与复阻抗欧姆定律是精确的；节点法和 ABCD 矩阵都是它的严格等价表述。
不属于本软件验证范围：麦克斯韦方程的全波解、微带线色散、介质损耗、辐射、连接器不连续性、元件寄生参数。

2. 基础定义

归一化阻抗：

z = Z / Z0
Γ = (Z − Z0) / (Z + Z0)
VSWR = (1 + |Γ|) / (1 − |Γ|)
S11(dB) = 20 log10 |Γ|
回波损耗(dB) = −S11(dB)

串联阻抗 Z 的 ABCD 矩阵：

[1  Z]
[0  1]

并联导纳 Y 的 ABCD 矩阵：

[1  0]
[Y  1]

级联网络按信号方向做矩阵乘法：

M_total = M_1 · M_2 · … · M_n
Zin = (A·Z_L + B) / (C·Z_L + D)

节点法：

Y · V = I
Vs_peak = sqrt(8·P·Z0)
I_source = Vs / Z0
Zin = V_s / I_in

两种方法一个是矩阵级联，一个是节点方程；它们不共享代码路径，因此可以互相发现符号、共轭、单位错误。

3. 五种拓扑的严格推导

以下记 ω = 2πf，Z0 = 50Ω，Z_L = R_L + jX_L。

3.1 L 型（右）：R_L < Z0

结构（信号方向）：

源(50Ω) — 并联 C1 — 串联 L+C2 — 负载 Z_L

从负载向源看，串联支路先加上 jX_s = j(ωL − 1/(ωC2))，再与源端并联组合共轭匹配。

设计式：

Q = sqrt(Z0/R_L − 1)
C1 = Q / (Z0 ω)
C2 = 1 / [ω (ωL + X_L − Q R_L)]

验证：

Z_after_series = R_L + jX_L + j(ωL − 1/(ωC2))
               = R_L + j Q R_L
Y_after_series = 1 / [R_L(1 + jQ)]
               = 1/Z0 − j Q/Z0        (因为 R_L(1+Q²)=Z0)
Y_in = 1/Z0 − jQ/Z0 + jωC1
     = 1/Z0                          (ωC1 = Q/Z0)
Zin = Z0

正向扫描的共轭：

Z_seen_from_load = conj( 1/(1/Z0 + jωC1) ) − j(ωL − 1/(ωC2))

V3.0 旧代码使用了 1/(1/Z0 − jωC1) − jX_s，既用了负电纳又没有取共轭，导致 L 型（右）可匹配区域镜像/偏移。V4.0 起已修正；test_physics.py 对扫描点逐点反算验证。

3.2 L 型（左）：R_L > Z0

结构：

源(50Ω) — 串联 L+C2 — 并联 C1 — 负载 Z_L

从负载先并联 C1：

Y_L = G_L + jB_L
B_tot = B_L + ωC1
Re{1/(G_L + jB_tot)} = Z0
G_L / (G_L² + B_tot²) = Z0
B_tot² = G_L/Z0 − G_L²

取正根（电容）：

C1 = (B_tot − B_L) / ω
X_par = Im{1/(G_L + jB_tot)}
C2 = 1/[ω(ωL + X_par)]

串联支路总电抗 ωL − 1/(ωC2) = −X_par，所以 Zin = Z0。

3.3 T 型

结构：

源 — 串联 C3 — 节点（并联 L+C2 到地）— 串联 C1 — 负载

源端串联 C3 后的等效阻抗：

Z_left = Z0 − j/(ωC3)
Y_left = 1/Z_left = G + jB_left
R_v = 1/G

负载经串联 C1 变换到同一节点，要求：

R_v ≥ R_L
X_b² = R_L/G − R_L²
X_b = X_L − 1/(ωC1)       （两个符号解，取 C1 为正）

节点电纳谐振：

B_right = Im{1/(R_L + jX_b)}
B_need = −(B_left + B_right)
1/(ωC2) = ωL + 1/B_need
C2 = 1/[ω(ωL + 1/B_need)]

3.4 π 型Ⅰ（C-L-C）

结构：

源 — 并联 C3 — 串联 L+C2 — 并联 C1 — 负载

Y_S = 1/Z0 + jωC3
Z_S = 1/Y_S
Δ = G_L/Re(Z_S) − G_L²
C1 = ( ±sqrt(Δ) − B_L ) / ω        （取最小正根）
Z_L' = 1/(G_L + j(B_L + ωC1))
X_branch = −(Im(Z_S) + Im(Z_L'))
C2 = 1/[ω(ωL + X_branch)]

串联支路总电抗等于 X_branch，使 Z_S + jX_branch + Z_L' = 0 的虚部条件成立，实部已由 C1 匹配。

3.5 π 型Ⅱ

结构：

源 — 并联 C1 — 串联 L+C2 — 并联 C3 — 负载

Z_Leff = 1/(1/Z_L + jωC3)
R_eff = Re(Z_Leff), X_eff = Im(Z_Leff)
Q = sqrt(Z0/R_eff − 1)
C1 = Q/(Z0ω)
X_S = −R_eff Q
X_req = −X_eff − X_S
C2 = 1/[ω(ωL − X_req)]

注意 C2 的分母必须为正；若为负，说明所选 L/C3 不在可行域，软件返回明确的 ok=false 与替代建议，而不是输出负电容。

4. 节点法复核

把每个拓扑展开成 2 或 3 节点网络：

  • L 型：2 节点；
  • T 型：3 节点（源、节点、负载）；
  • π 型：2 节点。

节点导纳矩阵：

Y[s,s] += 1/Z0
I[s] = Vs/Z0
串联支路 y=1/Z：Y[a,a]+=y, Y[b,b]+=y, Y[a,b]-=y, Y[b,a]-=y
并联支路 y：Y[a,a]+=y
负载：Y[l,l] += 1/Z_L

解 Y·V=I 后：

I_in = (Vs − V_s)/Z0
Zin = V_s/I_in
Γ = (Zin − Z0)/(Zin + Z0)
VSWR = (1+|Γ|)/(1−|Γ|)

元件电压/电流：

  • 串联：ΔV = V_a − V_b，I = ΔV/Z
  • 并联：V = V_a，I = V_a·y
  • 负载：V_load、I_load = V_load/Z_L

这才是“设计是否真的匹配”的最终判据。

5. 正向扫描的验证

正向扫描固定 L/C3，遍历 C1/C2/C3，计算：

Z_load = conj(Z_seen)

其中 Z_seen 是从负载端看进去的网络输入阻抗。扫描得到的每个点都应满足：

用该 Z_load 和对应的 C1/C2/C3 代回节点法 → Zin = Z0

test_physics.py::test_forward_scan_points_are_really_matched 对 L 型（右/左）的扫描网格逐点做了这个反算； 三元件拓扑则由随机设计与节点法/ABCD 双重验证覆盖。

6. Smith 圆图轨迹验证

build_steps 将匹配过程拆成串联/并联段：

  • 串联：Z → Z + jX，沿等电阻圆；
  • 并联：Y → Y + jB，沿等电导圆。

测试检查：

  1. 上一段终点 = 下一段起点（连续性）；
  2. 最后一段终点 = 圆心（|Γ| < 1e-6）；
  3. 每段 points_gamma 的首尾与段起止一致。

7. 功率、电压、电流

源用 Thevenin 等效：

Vs_peak = sqrt(8·P·Z0)
V_in_peak = Vs_peak/2 = sqrt(2·P·Z0)   （匹配时）

负载获得功率：

P_load = 0.5·|V_load|²·Re(1/Z_L)

无损网络匹配时 P_load = P_in、效率 = 1。测试对 10W、50Ω 输入验证：

  • input_voltage_peak = 31.6228 V；
  • delivered_power = 10 W；
  • efficiency = 1。

耐压界面的“输入峰值电压”是输入节点电压 V_in_peak，不是源开路电压 Vs_peak；两者相差 2 倍，已在 v4.0.0 修正显示。

9. 边界与工程提醒

  1. 理想元件：实际电感有 EPC、电容有 ESL，SRF 以上会改变符号；软件给出的是理想值。
  2. C < 0.1pF / L < 1nH：PCB 走线寄生会主导，软件会警告。
  3. 高 Q：带宽窄、对容差敏感；软件给出 ±5% 灵敏度。
  4. 强容性/强感性负载：固定电容拓扑可能无正解，软件返回物理原因，不输出负元件。
  5. 全波效应：微带不连续性、辐射、介质损耗需要 HFSS/CST/ADS 等全波或实测模型；本软件不替代全波仿真。
  6. MATLAB 原版 exe：经典界面保留 V3.0 行为；L 型（右）正向扫描修正位于 V4 新引擎。若需重新编译 exe，需 MATLAB Compiler + 原 .mlapp。

10. 结论

  • 在“理想无损集总参数网络”模型内，五种拓扑的解析解、节点法、ABCD 级联三者一致；
  • 正向扫描、轨迹、功率、VSWR 关系均有独立测试；
  • 不把“能运行”当作“算得对”：每个设计必须通过节点法复核才返回 ok=true；
  • 实际工程请用实测元件模型与全波/实测数据复核。
