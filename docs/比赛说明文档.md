## 一、创作背景

“微波技术”课程中，阻抗匹配既是重点也是难点：

- Smith 圆图抽象，学生很难把“串联沿等电阻圆、并联沿等电导圆”与具体元件值对应起来；
- L/T/π 网络公式多、符号容易写错，手算后缺少独立校验；
- 商用射频软件功能强大但学习门槛高，且无法用自然语言提问；
- 大模型能讲理论，却不能可靠地算出某个具体负载的匹配电容。

团队此前已用 MATLAB App Designer 开发了 V3.0 匹配软件（`Impedance_Matching.exe`），包含五种拓扑、Smith 圆图动画和耐压分析。但它仍然是一个“点按钮”的工具，不能与 AI 智能体协作。

因此，我们在 V3.0 基础上做了 V4.0：

> **保留原 MATLAB 内核，增加 Python/MATLAB 双计算引擎、MCP 标准接口、多模型工具调用智能体与现代化可视化界面。**
> 让软件既能“自己算”，也能“被 AI 调用”，成为一个微波仿真 MCP。

## 二、作品简介

智配芯生 · ImpedanceMCP 是一套“AI 智能体 + 微波仿真工具”的桌面软件：

- **会算**：五种拓扑的解析设计 + 完整网络节点法复核；
- **会画**：Smith 圆图逐步动画、VSWR 带宽、±5% 灵敏度、耐压柱状图；
- **会讲**：大模型调用本地工具，用微波工程语言解释结果；
- **会被调用**：15 个 MCP 工具，支持 stdio / Streamable HTTP / legacy SSE，ZCode / Claude Code / Codex / Cursor / Cherry Studio 等 MCP 客户端可直接使用；
- **会交付**：一键导出 HTML/Markdown 报告。

## 三、创新点

### 1. 把“软件”变成“MCP 服务”

传统 EDA 工具只能人机交互；本作品把匹配计算、扫描、复核、耐压、报告封装成 15 个 MCP 工具，任何支持 MCP 的智能体都能调用：

```text
用户：帮我把 2.4GHz 的 20+j5Ω 匹配到 50Ω，并分析 10W 耐压。
智能体：调用 design_matching_network → 得到 L=1.939nH、C1=1.624pF、C2=6.803pF
        调用 compute_voltage_stress → 得到 C1 峰值电压 31.6V
        用工程语言解释 → 给出选型建议
```

这不是“让大模型背公式”，而是**让大模型调用真实计算引擎**，从根源上减少幻觉。

### 2. 解析解 + 节点法双重校验

每个设计先用拓扑公式求元件值，再把整个网络展开成节点矩阵，独立计算 `Zin/VSWR/S11`。如果公式符号或单位写错，节点法会立即暴露。

- 300 组随机用例：VSWR 全部 1.000000；
- MATLAB R2025b 交叉验证：5/5 通过，Zin 偏差 0.0；
- 还修复了 V3.0 L 型（右）正向扫描的共轭符号错误。

### 3. 双引擎 + 经典 exe 外壳

- Python 内核：毫秒级，无 MATLAB 也能用；
- MATLAB R2025b：一键复核；
- 原版 `Impedance_Matching.exe`：保留教学动画与经典界面，一键启动；
- **独立 Windows exe**：双击即可运行完整界面，不需要 MCP、不需要 AI 客户端；
- **214 家模型服务商**：来自 models.dev，国内外主流厂商全部可选，**不设默认厂商/模型/Key**。

### 4. 面向教学的 Smith 圆图动画

- 三段/四段轨迹逐段绘制；
- 鼠标悬停显示 Z/Γ/VSWR；
- 步骤卡片与轨迹联动；
- 带宽、灵敏度、耐压同屏呈现。

### 5. 工程化的可复现验证

- 8 项引擎回归测试；
- 11 项 MCP 协议测试；
- 原生 WebView2 窗口逐页视觉验收；
- 报告与界面使用同一组精确元件值。

## 五、操作指南（5 分钟演示）

### 步骤 1：启动

**方式 A（推荐，无需 Python）**：

```text
双击 release/ImpedanceMCP.exe
```

**方式 B（源码）**：

```bat
pip install numpy pypdf openpyxl Pillow
start_app.bat
```

双击 `ImpedanceMCP.exe` 打开原生窗口；源码调试可运行 `python app\run_app.py --browser`。

### 步骤 2：AI 对话

先在「设置」中选择服务商、模型并填写自己的 API Key（软件不设默认厂商），然后在「AI 智能体」输入：

> 在 2.4 GHz 把 20+j5 Ω 匹配到 50 Ω，给出元件值、VSWR 和带宽。

预期：

- 智能体调用 `design_matching_network`；
- 返回 L=1.939 nH、C1=1.624 pF、C2=6.803 pF；
- VSWR=1.0000，带宽约 57%；
- 生成设计卡片与圆图缩略图。

![AI 智能体](assets/screenshot_agent.png)

### 步骤 3：打开设计页

点击设计卡片的「在设计中打开」：

- 查看 Smith 圆图动画；
- 查看步骤、公式、带宽、灵敏度；
- 点击「MATLAB 复核」做独立复算（约 15–20 秒）。

![设计界面](assets/screenshot_design.png)

### 步骤 4：扫描与对比

点击「扫描范围」：

- 查看 L 型（右）可匹配的 R/X 区域；
- 自动比较五种拓扑，查看带宽/Q；
- 点击「应用」切换方案。

![圆图分析](assets/screenshot_analysis.png)

### 步骤 5：耐压

进入「耐压分析」→「从当前设计填入」→「开始耐压分析」：

- 输入峰值电压 31.6 V（10 W）；
- C1 峰值电压 31.6 V，L+C2 19.5 V；
- 可填额定电压计算安全系数。

![耐压分析](assets/screenshot_stress.png)

### 步骤 6：报告

点击「导出报告」→ 原生子窗口打开 HTML → `Ctrl+P` 保存 PDF。

![报告](assets/screenshot_report.png)

### 步骤 7：MCP 演示

在 ZCode 中：

> 用 impedance-matching 工具设计 100−j30Ω、2.4GHz 的匹配，比较 L 型和 T 型。

智能体会调用 `compare_topologies` / `design_matching_network`，并把工具结果作为回答依据。

客户端配置示例：

- **Claude Code**：`claude mcp add impedance-matching -- "...\ImpedanceMCP.exe" --mcp`
- **Codex**：`~/.codex/config.toml` 的 `[mcp_servers.impedance-matching]`
- **ZCode**：`~/.zcode/cli/config.json` 的 `mcp.servers`
- **Cherry Studio**：先 `--mcp --http 8790`，添加 SSE `http://127.0.0.1:8790/sse`

> MCP 需要客户端支持；没有 MCP 入口的聊天软件无法加载任何 MCP 服务器，这不是本软件协议的问题。即使不接 MCP，双击 exe 也能独立运行完整功能。

## 六、技术实现

### 6.1 计算

- 五种拓扑解析解；
- 2/3 节点导纳矩阵，源 50Ω Thevenin，负载 `Z_L`；
- `Zin = V_s / I_in`；
- 带宽：±60% 扫频 241 点；
- 灵敏度：元件 ±5% 重算；
- 耐压：节点电压直接算元件应力。

### 6.2 MCP

- JSON-RPC 2.0；
- 三种传输：stdio、Streamable HTTP（`/mcp` + `Mcp-Session-Id`）、legacy HTTP+SSE（`/sse` + `/messages`）；
- 协议版本：2024-11-05 / 2025-03-26 / 2025-06-18；
- `initialize` / `tools/list` / `tools/call` / `resources` / `prompts`；
- 15 个工具、3 个资源、3 个提示；
- 日志写 stderr，stdout 只输出协议 JSON；
- 只监听 `127.0.0.1`，校验 Origin。

### 6.3 智能体

- 214 家模型服务商目录（models.dev），不设默认厂商/模型/Key；
- OpenAI 兼容 + Anthropic 原生 + Azure OpenAI 适配；
- 工具循环最多 5 轮；
- 系统提示要求“先算后说”；
- 附件解析（PDF/DOCX/XLSX/PPTX/Notebook）；
- SSE 流式事件。

### 6.4 前端

- 原生 HTML/CSS/JS，无构建步骤；
- Canvas 2D Smith 圆图；
- 响应式布局；
- 深色工程控制台主题；
- 报告使用浅色 A4 打印样式。

## 九、总结

智配芯生 · ImpedanceMCP 不是“给旧软件套一个聊天框”，而是把微波匹配计算重新组织成**可被智能体调用的能力**：

- 对学习者：圆图动画 + 对话解释，降低理解门槛；
- 对工程师：解析解 + 节点法 + 带宽/容差/耐压，直接可用于方案评估；
- 对 AI 生态：15 个 MCP 工具 + 三种传输，让大模型“算得准、说得清”；
- 对教学：保留原 MATLAB 软件，形成“经典内核 + 现代外壳”的渐进式升级。

我们希望通过这个作品说明：**AI 不是替代专业工具，而是让专业工具更容易被使用、被验证、被复用。**
