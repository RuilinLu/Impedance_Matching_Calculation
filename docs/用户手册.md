## 1. 软件简介

智配芯生 · ImpedanceMCP 是一套面向微波工程学习与设计的阻抗匹配软件。它由三部分组成：

1. **经典 MATLAB 内核**：原版 `Impedance_Matching.exe`（V3.0，App Designer + RF Toolbox），保留原有 L/T/π 五种拓扑、Smith 圆图动画与耐压分析。
2. **Python 智能外壳**：现代化 Web 界面、独立计算内核、多模型对话、附件解析、报告导出。
3. **MCP 服务器**：把匹配计算、扫描、复核、耐压、报告等能力封装成 15 个标准工具，可被 ZCode、Claude、Cursor 等任意 MCP 客户端调用。

> 一句话：**它既是一个更好用的匹配设计软件，也是一个能被 AI 智能体调用的微波仿真 MCP。**

## 2. 安装与启动

### 2.1 独立软件（推荐）

#### 方式 A：Windows exe（无需 Python）

```text
双击 release/ImpedanceMCP_v4.1.0_Windows.exe
```

- 自动启动本地 Web 界面并打开浏览器；
- 默认端口 8765，被占用会自动尝试 8766–8776；
- 不连接任何 AI、不需要 MCP 也能完成全部计算；
- 用户数据保存在 `%LOCALAPPDATA%\ImpedanceMCP\data\`（配置、上传、报告）。

#### 方式 B：源码运行

运行环境：

- Windows 10/11（64 位）
- Python **3.10 或更高**（推荐 3.11–3.14）
- 依赖：`numpy`
- 可选：`pypdf`、`openpyxl`、`Pillow`（用于 PDF/XLSX/图片附件）

```bat
cd "项目根目录"
pip install numpy pypdf openpyxl Pillow
start_app.bat
```

或：

```bat
python app\run_app.py
```

启动后默认打开 `http://127.0.0.1:8765/`。端口被占用时会自动尝试后续端口（8766–8776）。

#### 停止

关闭命令行窗口，或在窗口中按 `Ctrl+C`。双击 exe 启动的版本关闭命令行窗口即可。

### 2.2 原版 MATLAB 软件

原版 `Impedance_Matching.exe` 由 MATLAB R2023b 编译，运行需要：

1. **Visual C++ 运行库**：`Problem_Solution/VC_redist.x64.exe`
2. **MATLAB Runtime R2023b Update 10**

两种安装方式：

| 方式 | 文件 | 是否需要单独装 Runtime |
|---|---|---|
| 安装包（推荐） | `Main_Installation/MyAppInstaller_mcr.exe` | **不需要**，安装包已内置 Runtime |
| 便携 exe | `for_redistribution_files_only/Impedance_Matching.exe` | **需要**，先装 Runtime 与 VC++ |

> `MyAppInstaller_mcr.exe` 的工程配置为 `package.mcr=true`，这是 MATLAB Compiler 的“包含 Runtime”安装包，约 974 MB。直接双击安装即可。
>
> 便携版 exe 只有约 2.5 MB，必须依赖已安装的 MATLAB Runtime R2023b；如果目标电脑没有 MATLAB，请使用安装包方式。

安装完成后，可以在软件右上角点击「打开原版」启动经典界面。

### 2.3 配置模型服务（无默认厂商）

软件内置 **214 家模型服务商**目录（来自开源项目 models.dev），**不设默认厂商、不设默认模型、不内置任何 Key**。是否使用 AI 完全由你决定；不配置也能使用全部计算功能。

打开右上角「设置」：

1. 在「服务商」下拉框选择厂商（常用厂商在顶部，其余在“全部服务商”分组）；
2. Base URL 会自动填入，也可以手动修改；
3. 在「模型 ID」选择模型；如果列表里没有，使用「自定义模型 ID」填写；
4. 填写你在该厂商控制台申请的 API Key；
5. 点击「测试连接」。

目录覆盖（部分）：

| 服务商 | Base URL 示例 | 模型示例 |
|---|---|---|

特殊适配：

- **Anthropic Claude**：使用 Messages 原生协议（已适配工具调用）；
- **Azure OpenAI**：`api-key` 头 + 部署名 + `api-version`，按提示替换 `<resource>` / `<deployment>`；
- **其他厂商**：统一走 OpenAI 兼容 `/chat/completions`。

环境变量（可选，仍然不设默认厂商）：

```bat
set LLM_BASE_URL=https://api.deepseek.com/v1
set LLM_API_KEY=sk-...
set LLM_MODEL=deepseek-chat
```

- API Key 只保存在本机：exe 为 `%LOCALAPPDATA%\ImpedanceMCP\data\config.json`，源码为 `data/config.json`，不会写入 Git 仓库。
- 点击「测试连接」会发送一条最小请求，显示延迟与模型名。
- 建议选择支持 **tool calling** 的模型；不支持工具调用的模型仍可聊天，但不会自动调用匹配工具。
- 出于安全策略，模型服务地址不能指向本机/内网；本地模型请通过公网网关或反向代理。

### 2.4 可选：MATLAB R2025b 复核

如果本机安装了 MATLAB R2025b，软件可以调用 `matlab -batch` 对设计做独立复算：

- 在「设置 → 计算引擎」选择 `MATLAB R2025b`，或直接在设计页点击「MATLAB 复核」。
- 单次复核约 15–20 秒（MATLAB 启动时间占大部分）。
- 没有 MATLAB 不影响默认的 Python 计算。

## 4. AI 智能体

### 4.1 基本用法

先在「设置」中选择服务商、模型并填写自己的 API Key，然后在底部输入框描述需求，例如：

- “在 2.4 GHz 把 20+j5 Ω 匹配到 50 Ω，给出元件值和 VSWR。”
- “比较 L 型、T 型和 π 型，哪种更适合 100−j30 Ω 的高阻负载？”
- “为 433 MHz、15 Ω 的负载设计匹配网络，并分析 ±5% 容差和 10 W 耐压。”
- “解释史密斯圆图上串联电感和并联电容的轨迹方向。”

按 Enter 发送，Shift+Enter 换行。输入框右侧可选择模型。

### 4.2 智能体如何工作

1. 理解你的问题；
2. 调用本地 MCP 工具（设计、扫描、复核、耐压、知识库等）；
3. 读取工具返回的数值；
4. 用微波工程语言解释结论、公式和注意事项。

工具调用过程会以卡片形式显示在回答中：

- 工具名与中文标签
- 运行状态与耗时
- 结果摘要
- 可展开的原始 JSON

### 4.3 设计卡片

当工具返回一次完整设计时，对话中会出现一张设计卡：

- 电感 L、C1、C2、C3
- VSWR、S11、带宽、Q
- 「在设计中打开」「导出报告」按钮

点击「在设计中打开」会把参数填入匹配设计页，并加载完整圆图轨迹。

### 4.4 附件

点击输入框左侧的回形针上传附件。支持：

| 类型 | 扩展名 |
|---|---|
| 文本/代码 | `.txt .md .csv .json .xml .yaml .py .m .c .h .cpp .js .html .tex .log` |
| 文档 | `.pdf .docx` |
| 表格/演示 | `.xlsx .xlsm .pptx` |
| Notebook | `.ipynb` |
| 图片 | `.png .jpg .jpeg .bmp .gif .webp` |

- 单文件最大 25 MB。
- PDF 最多读取 80 页，单个附件最多 60,000 字符（超出会截断）。
- 文本模型不读取图片内容；图片会保存并提示用文字描述。
- 附件内容只作为资料，智能体不会执行附件中的“指令”。

### 4.5 右侧上下文

“当前设计上下文”显示最近一次设计：

- 元件值、VSWR、带宽
- 圆图缩略图
- 「在设计中打开」「导出报告」

“MCP 工具”列出 15 个工具及其用途；底部可复制 ZCode 配置。

### 4.6 使用建议

- 问题里尽量包含频率、负载 R/X、功率、带宽要求。
- 不确定拓扑时直接说“自动选型”。
- 需要工程建议时，明确问“容差/耐压/带宽/可实现性”。
- 如果智能体给出无解，让它“比较其他拓扑”。

## 5. 匹配设计

### 5.1 输入参数

| 参数 | 说明 |
|---|---|
| 频率 | 工作频率，MHz |
| 系统阻抗 Z0 | 默认 50 Ω |
| 负载实部 R_L | Ω，必须 > 0 |
| 负载虚部 X_L | Ω，可为负（容性） |
| 拓扑 | 自动 / L·右 / L·左 / T / πⅠ / πⅡ |
| 自动选值 | 开启时自动选择 L 与 C3 |
| 电感 L | µH；关闭自动选值后手动输入 |
| 电容 C3 | pF；T/π 型可手动输入 |

### 5.2 拓扑选择

| 拓扑 | 适用条件 | 特点 |
|---|---|---|
| L 型（右） | R_L < 50 Ω | 元件最少，效率高 |
| L 型（左） | R_L > 50 Ω | 高阻负载 |
| T 型 | 需要中间节点调节 | 三元件，可调带宽 |
| π 型Ⅰ | C-L-C 结构 | 两个并联电容，自由度更高 |
| π 型Ⅱ | 低阻负载 | 源端/负载端均可调 |
| 自动 | 不确定时 | 比较五种拓扑，优先 L 型 |

> 固定电容拓扑存在物理不可行区：强容性负载可能让 C1/C2 出现负值。此时软件会返回明确的无解原因，并建议替代拓扑。

### 5.3 求解

点击「求解设计」。软件会：

1. 读取参数并做单位换算；
2. 按拓扑公式求 C1、C2（必要时自动选 L/C3）；
3. 用完整网络节点法复核 `Zin`、`VSWR`、`S11`；
4. 计算带宽、灵敏度、工程风险；
5. 在 Smith 圆图上生成三段/四段轨迹。

### 5.4 结果卡片

顶部四个 KPI：

- **VSWR**：目标 < 1.5；1.0000 表示完全匹配。
- **S11**：低于 −60 dB 时显示“< −60 dB（理想）”。
- **带宽**：VSWR < 2 的分数带宽。
- **设计 Q**：越低越宽。

### 5.5 Smith 圆图

- 点击播放按钮开始动画；暂停/重置/速度滑块在右上角。
- 轨迹颜色对应步骤：串联 C2、串联 L、并联 C1 等。
- 鼠标悬停可查看该点的 Z、Γ、VSWR。
- 点击右侧步骤卡片可跳到该段轨迹终点。

### 5.6 带宽与灵敏度

- **VSWR 带宽**：固定元件值，在 ±60% 频率范围内扫频；阴影为 VSWR<2 频段。
- **±5% 灵敏度**：分别把每个元件偏离 ±5%，计算最差 VSWR；绿色 <1.5，黄色 <2，红色 ≥2。

### 5.7 工程提示

软件会自动提示：

- C1/C2 < 0.1 pF：寄生参数可能主导。
- L < 1 nH：PCB 走线电感不可忽略。
- Q > 20：带宽窄、对容差敏感。
- 元件值超出常规范围。

### 5.8 可选拓扑对比

自动模式下会列出其他可行拓扑的元件值、带宽、Q，点击「应用此方案」即可切换。

### 5.9 MATLAB 复核

点击「MATLAB 复核」会：

- 用当前拓扑与 L/C3 调用 MATLAB R2025b；
- 在 MATLAB 中重新解析求解并用节点法复核；
- 返回 `Zin`、`VSWR`、耗时。

要求本机安装 MATLAB R2025b；否则会提示不可用。

## 6. 圆图分析

![圆图分析](assets/screenshot_analysis.png)

### 6.1 正向扫描

1. 选择拓扑；
2. 输入频率、Z0、固定电感 L；
3. 设置 C1/C2/C3 的可调范围；
4. 点击「运行扫描」。

结果：

- 可匹配负载的 **R 范围**、**X 范围**；
- 有效扫描点数；
- 圆图上的扫描点云；
- 自动生成的扫描结论；
- 五种拓扑的可行性与带宽对比。

### 6.2 如何理解

- 点云覆盖的区域就是该拓扑 + 固定 L + 电容范围能匹配的负载集合。
- 目标负载落在区域外时，可以：
  - 调整 L；
  - 扩大电容范围；
  - 换三元件拓扑；
  - 检查负载是否强容性/强感性。

### 6.3 拓扑对比

点击「重新比较」会调用 `compare_topologies`，列出五种拓扑的元件值、带宽、Q 与推荐排序。点击「应用」可直接回到设计页。

## 7. 耐压分析

![耐压分析](assets/screenshot_stress.png)

### 7.1 输入

- 拓扑、频率、负载 R/X；
- L、C1、C2、C3；
- 输入功率（W）；
- 元件额定电压（可选，用于安全系数）。

点击「从当前设计填入」可自动读取最近一次设计。

### 7.2 输出

- 输入峰值电压、源开路电压；
- 负载峰值电压；
- 各元件峰值电压、RMS 电压、峰值电流、RMS 电流；
- 安全系数 = 额定电压 / 峰值电压；
- 柱状图与工程建议。

### 7.3 注意

- 计算使用完整网络节点法，包含 50Ω 源阻抗的负载效应。
- 峰值电压不是简单的“源电压”，高 Q 节点可能远高于输入电压。
- 选型时建议额定值 ≥2× 峰值，并考虑温度降额与寄生。

## 9. MCP 接入

本软件既是**独立可运行软件**，也是 **MCP 服务器**。MCP 只是可选的集成方式：不接 MCP 也能正常设计与计算。

### 9.1 三种传输

| 传输 | 启动 | 适用 |
|---|---|---|
| stdio | `ImpedanceMCP.exe --mcp` | Claude Code / Codex / ZCode / Cursor / Claude Desktop |
| Streamable HTTP | `ImpedanceMCP.exe --mcp --http 8790` | 支持 HTTP 的客户端 |
| legacy HTTP+SSE | 同上，`GET /sse` | Cherry Studio / 旧版 MCP 客户端 |

源码方式：

```bat
python app\run_mcp.py                 :: stdio
python app\run_mcp.py --http 8790     :: HTTP + SSE
```

### 9.2 ZCode

配置位置：`~/.zcode/cli/config.json` 的 `mcp.servers`。exe 方式：

```json
{
  "mcp": {
    "servers": {
      "impedance-matching": {
        "type": "stdio",
        "command": "C:\\path\\to\\ImpedanceMCP_v4.1.0_Windows.exe",
        "args": ["--mcp"],
        "timeoutMs": 120000
      }
    }
  }
}
```

Python 方式：

```json
{
  "mcp": {
    "servers": {
      "impedance-matching": {
        "type": "stdio",
        "command": "C:\\Python314\\python.exe",
        "args": ["D:\\path\\to\\app\\run_mcp.py"],
        "env": {"PYTHONUNBUFFERED": "1", "PYTHONIOENCODING": "utf-8"},
        "timeoutMs": 120000
      }
    }
  }
}
```

**完全退出并重启 ZCode** 后，工具会以 `mcp__impedance-matching__*` 的形式出现。

### 9.3 其他客户端

- **Claude Code**：`claude mcp add impedance-matching -- "C:\path\to\ImpedanceMCP_v4.1.0_Windows.exe" --mcp`
- **Claude Desktop**：`claude_desktop_config.json` 的 `mcpServers`
- **Codex CLI**：`~/.codex/config.toml` 的 `[mcp_servers.impedance-matching]`
- **Cursor**：`.cursor/mcp.json`
- **Cherry Studio**：先 `--mcp --http 8790`，再添加 SSE `http://127.0.0.1:8790/sse`
- **Chatbox**：较新版本支持 MCP；旧版没有入口，无法加载任何 MCP 服务器

## 10. 常见问题

### Q1：`MyAppInstaller_mcr.exe` 包含 Runtime 吗？

包含。工程配置 `package.mcr=true`，安装包内置 MATLAB Runtime R2023b，直接安装即可。
便携版 exe 才需要单独安装 `MATLAB_Runtime_R2023b_Update_10_win64.zip`。

### Q2：为什么还需要 VC_redist？

MATLAB 编译生成的 exe 依赖 Visual C++ 运行库。若目标电脑缺少，会提示缺少 DLL。
安装 `Problem_Solution/VC_redist.x64.exe` 即可。

### Q3：没有 MATLAB 能用吗？

能。独立 exe / 默认 Python 内核完成所有计算、绘图、MCP 工具与 AI 对话。
MATLAB 只用于“MATLAB 复核”和“打开原版 exe”。

### Q3b：为什么设置里没有默认模型厂商？

这是刻意设计。软件内置 214 家服务商，但不替用户选择；你需要自己选择厂商、模型并填写自己的 API Key。这样国内外模型都可用，也不绑定任何一家。

### Q3c：这个软件能自己运行吗？

能。双击 `ImpedanceMCP_v4.1.0_Windows.exe` 即打开独立界面，不连接 MCP、不配置 AI 也能完成全部设计与计算。

### Q3d：MCP 是不是所有 AI 软件都能用？

不是。MCP 是标准，但客户端必须实现 MCP。Claude Code / Codex / ZCode / Cursor / Cherry Studio 等支持 MCP 的客户端可以接入；没有 MCP 入口的聊天软件无法加载任何 MCP 服务器。详见 [MCP 兼容性说明](MCP兼容性说明.md)。

### Q4：模型返回 401 / 403 / 404 / 超时？

- 401：Key 无效或过期。
- 403：Key 没有该模型的权限，或账号未开通。
- 404：Base URL、模型 ID 或 Azure 部署名不对。
- 超时：网络/代理问题，或问题过长。
- DeepSeek 示例：`https://api.deepseek.com` + `deepseek-flash` / `deepseek-v4-flash`（以服务商控制台实际模型为准）。

### Q5：设计无解 / C2 为负？

固定电容拓扑的物理限制。尝试：

- 换 `自动` 或其他拓扑；
- 调整 L/C3；
- 检查负载是否强容性/强感性；
- 降低频率或改用电感型网络。

### Q6：C2 只有 0.00x pF？

手动 L 太大。打开“自动选值”，或把 L 减小到 1–10 nH。

### Q7：端口被占用？

程序会自动尝试 8766–8776。也可以手动指定：

```bat
ImpedanceMCP_v4.1.0_Windows.exe --port 8899
:: 或
python app\run_app.py --port 8899
```

### Q8：ZCode 看不到工具？

1. 检查配置 JSON 语法；
2. 确认 `args` / exe 路径存在；
3. 先运行 `ImpedanceMCP_v4.1.0_Windows.exe --mcp` 或 `python app\run_mcp.py`，看是否有报错；
4. 完全退出并重启 ZCode。

### Q9：浏览器打不开 / 白屏？

- 确认命令行窗口没有报错；
- 尝试 `http://127.0.0.1:8765/`；
- 清除浏览器缓存或换 Edge/Chrome；
- 查看终端日志。

### Q10：报告中文乱码？

报告使用 UTF-8；浏览器应自动识别。若用旧版编辑器打开，请选择 UTF-8。
