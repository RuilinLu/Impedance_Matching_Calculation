安装与卸载

安装

  1. 运行 Impedance_Matching_AI_v4.4.0_Setup.exe。
  2. 选择安装目录（默认 %LOCALAPPDATA%\Programs\Impedance Matching AI）。程序、MCP 服务与 TextBook/ 会跟随所选目录。
  3. 安装程序会安装原生窗口、MCP 服务、离线说明书与 MathJax，并创建桌面/开始菜单快捷方式。
  4. 首次启动会创建用户数据目录（%LOCALAPPDATA%\ImpedanceMatchingAI）与教材数据库。

移动安装位置

程序目录中的 TextBook 会按当前安装位置动态解析，移动程序后无需手改路径。可把旧教材复制到新目录的 TextBook，或在“教材库 → 路径管理”中添加旧目录并调整优先级。若使用自定义数据目录，可在程序目录放置 data_root.txt，写入数据目录的绝对路径。

目录结构

Impedance Matching AI/
  ImpedanceMatchingAI.exe         主程序（原生 WebView2 窗口）
  ImpedanceMatchingAI_MCP.exe     MCP stdio / HTTP 服务
  docs/                            离线说明书（HTML + 截图 + MathJax）
  TextBook/                        随安装目录变化的教材入口（可选）
  data_root.txt                    可选：自定义用户数据目录
%LOCALAPPDATA%/ImpedanceMatchingAI/
  data/                            配置、教材索引、上传、报告、更新缓存
  TextBook/                        保留/迁移的教材
  webview/                         WebView2 缓存

卸载

开始菜单或桌面“一键卸载 Impedance Matching AI”会：

  • 关闭正在运行的主程序与 MCP 进程；
  • 删除程序文件、快捷方式、注册表项与 MCP 客户端配置；
  • 询问是否保留个人数据：选择“是”保留 API Key、界面设置、教材索引、上传/报告、翻译缓存与教材搜索路径，重装后可直接复用；选择“否”彻底删除 %LOCALAPPDATA%\ImpedanceMatchingAI 下的数据。
  • 保留模式下，程序目录 TextBook 中的文件会先复制到用户数据目录，再删除程序目录；自定义教材搜索目录永远不会被卸载程序删除。
  • 不会删除共享的 Microsoft Edge WebView2 Runtime。

系统要求

Windows 10/11 x64；Microsoft Edge WebView2 Runtime（安装程序会自动检测/安装）。

Impedance Matching AI v4.4.0 · 教材与用户数据保存在本机，不上传。MathJax 3.2.2 (Apache-2.0)。
