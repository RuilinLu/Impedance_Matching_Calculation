安装指南与目录说明

先回答最常见的问题：MyAppInstaller_mcr.exe 已经内置 MATLAB Runtime， 直接双击安装即可，不需要再单独安装 Runtime。只有使用便携版 for_redistribution_files_only/Impedance_Matching.exe 时，才需要单独安装 VC_redist.x64.exe 与 MATLAB_Runtime_R2023b_Update_10_win64.zip。

1. 三种使用方式

A. 独立软件（推荐）

双击即用：AI 对话 + 五种拓扑 + Smith 圆图 + MCP 工具 + 报告；不需要 Python，也不需要 AI 客户端。

ImpedanceMCP_v4.1.0_Windows.exe

源码方式：start_app.bat（需要 Python）

B. 原版安装包（经典界面）

内置 Runtime，双击安装；安装后可从新版右上角「打开原版」启动。

Main_Installation/MyAppInstaller_mcr.exe

C. 便携版 exe

体积小，但依赖已安装的 Runtime 与 VC++ 运行库。

.../for_redistribution_files_only/Impedance_Matching.exe

D. MCP 服务

让 ZCode / Claude Code / Codex / Cursor / Cherry Studio 调用 15 个微波仿真工具；支持 stdio / HTTP / SSE。

python app\run_mcp.py

2. 安装新版智能外壳

  1. 确认 Windows 10/11 64 位，安装 Python 3.10+（推荐 3.11–3.14），勾选 “Add Python to PATH”。
  2. 在项目根目录打开命令行，执行： 
    pip install numpy pypdf openpyxl Pillow
    numpy 是计算必需；其余用于 PDF/XLSX/图片附件解析，可选。
  3. 双击 start_app.bat，或在命令行执行 python app\run_app.py。
  4. 浏览器自动打开 http://127.0.0.1:8765/；若端口被占用，会自动尝试 8766–8776。
  5. 点击右上角「设置」，选择服务商与模型（214 家国内外厂商，无默认），填写你自己的 API Key，点击「测试连接」。
不需要 MATLAB 也能用新版：默认 Python 内核完成全部计算、绘图、报告与 MCP 工具。 MATLAB 只用于「MATLAB 复核」和「打开原版 exe」。

3. 安装原版 MATLAB 软件

方式 A：安装包（推荐）

  1. 双击 APP_Release_Release_Version/Main_Installation/MyAppInstaller_mcr.exe（约 974 MB）。
  2. 按向导安装到默认目录或 D:\Impedance_Matching。
  3. 安装完成后，从开始菜单或新版右上角「打开原版」启动。
该安装包由 MATLAB Application Compiler 生成，工程配置 package.mcr=true， Runtime 已打包在安装程序内，无需再安装 Runtime。

方式 B：便携版 exe

  1. 先安装 APP_Release_Release_Version/Problem_Solution/VC_redist.x64.exe。
  2. 解压并安装 Problem_Solution/MATLAB_Runtime_R2023b_Update_10_win64.zip 中的 Runtime。
  3. 双击 .../for_redistribution_files_only/Impedance_Matching.exe。
便携版只有约 2.5 MB，必须依赖本机已安装的 MATLAB Runtime R2023b。若评委电脑没有 MATLAB， 请使用方式 A，或先把 Runtime 安装好。

5. 接入 ZCode / MCP

把下面这段加入 ~/.zcode/cli/config.json 的 mcp.servers， 把 args 改成你本机的绝对路径，重启 ZCode：

{
  "mcp": {
    "servers": {
      "impedance-matching": {
        "type": "stdio",
        "command": "C:\\path\\to\\ImpedanceMCP_v4.1.0_Windows.exe",
        "args": ["--mcp"],
        "timeoutMs": 120000
      }
    }
  }
}

重启后即可在 ZCode 中使用 15 个工具，例如：

用 impedance-matching 工具设计 2.4 GHz、20+j5 Ω 的匹配网络，
并分析 ±5% 容差和 10 W 耐压。
手动测试：python app\run_mcp.py 后发送一行 {"jsonrpc":"2.0","id":1,"method":"initialize",...}。 HTTP 模式：python app\run_mcp.py --http 8790。

7. 常见问题

Q1：安装包需要联网吗？

不需要。Runtime 与程序都在本地；新版外壳的 MCP/计算也全部本地运行，只有 AI 对话需要联网。

Q2：可以只拷贝 APP_Release_Release_Version 文件夹到评委电脑吗？

如果只用原版 exe，可以。新版智能外壳需要项目根目录的 app/、start_app.bat 与 Python 环境； 建议整体拷贝项目，或使用 Release 中的源码包。

Q3：模型 401 / 403 / 404？

401 是 Key 无效；403 是没有该模型权限；404 是 Base URL、模型 ID 或 Azure 部署名不对。 在设置里重新选择服务商并检查控制台。

Q4：设计无解？

固定电容拓扑对强容性/强感性负载有物理限制。换 auto 或其他拓扑， 或调整 L/C3；软件会给出具体原因。

Q5：端口被占用？

程序会自动尝试后续端口；也可手动 python app\run_app.py --port 8899。
