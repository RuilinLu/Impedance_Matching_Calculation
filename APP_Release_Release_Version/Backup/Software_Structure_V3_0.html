2. 核心模块详解 (Module Breakdown)

2.1 主程序与入口 (Main Entry)

Core MW_V1.mlapp

功能： 软件的“大脑”和主入口。

  • 负责初始化主界面 UI (Tab页切换、按钮响应)。
  • 接收用户输入的频率、阻抗等参数。
  • 调用 Smith_Plot 中的算法进行计算。
  • 调用 Readme 和 Voltage 子窗口。
  • 管理 startupFcn 初始化逻辑。
Config Impedance_Mctching.prj

功能： MATLAB Compiler 的工程配置文件。

  • 记录了打包成 exe 所需的所有文件依赖关系。
  • 包含 App 名称、作者、版本 (2.0/3.0)、图标设置。
  • 定义了是否包含 MATLAB Runtime。

2.2 核心算法与绘图逻辑 (Logic & Plotting)

Logic Smith_Plot 文件夹

包含文件： SmithAnimator_*.m 系列脚本。

设计模式： 为了避免 App Designer 代码过于臃肿，复杂的 Smith 圆图动态绘制逻辑被剥离为独立的纯 MATLAB 脚本 (.m)。

  • LLeft/LRight: 处理 L 型匹配的感性/容性路径计算。
  • T/pi1/pi2: 处理三元件复杂匹配的路径迭代。
  • 技术点： 使用 RF Toolbox 的 smithplot 函数绘制背景，使用 line 对象绘制动态轨迹。

2.3 辅助功能子系统 (Sub-Apps)

UI View Readme 文件夹

包含文件： Readme_*.mlapp

功能： 独立的帮助文档窗口。

  • 当用户在主界面点击“？”或帮助按钮时弹出。
  • 内置了对应电路拓扑的原理图 (Image) 和详细文字说明 (HTML Label)。
  • 采用模态或非模态窗口设计，不干扰主程序运行。
Calc Voltage 文件夹

包含文件： Component_Voltage_All.mlapp

功能： 独立的工程计算器。

  • 计算匹配网络中各电感、电容在特定功率下的电压/电流应力。
  • 辅助用户进行元件选型。

作用： 存储电路原理图、软件 Logo、示意图等静态资源。主程序在运行时会动态读取此文件夹下的图片并显示在 UI 上。
