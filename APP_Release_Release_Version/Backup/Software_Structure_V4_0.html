1. 与 V3.0 的关系

V3.0 是基于 MATLAB App Designer R2023b 的单体应用：

MW_V1.mlapp
├─ Smith_Plot/SmithAnimator_*.m
├─ Readme/Readme_*.mlapp
├─ Voltage/Component_Voltage_All.mlapp
└─ Figure/*.png

V4.0 保留 V3.0 的： - 五种拓扑与解析公式； - Smith 圆图动画思路； - 原版 Impedance_Matching.exe； - 耐压分析的教学目标。

V4.0 新增： - Python 计算内核与完整网络节点法复核； - 15 个 MCP 工具； - 多模型工具调用智能体与附件解析； - 现代化 Web UI； - HTML/Markdown 报告； - MATLAB R2025b 批处理复核； - 自动化测试与文档。

3. 模块说明

3.1 engine.py：计算内核

职责：

  • 五种拓扑的反向解析设计；
  • 自动 L/C3 选取；
  • 完整网络节点法复核；
  • 正向匹配范围扫描；
  • VSWR 带宽、±5% 灵敏度；
  • 元件耐压/电流应力；
  • Smith 圆图轨迹生成；
  • 阻抗/导纳换算。

关键对象：

函数 说明
design_network(...) 主入口；topology="auto" 自动比较五种拓扑
analyze_network(...) 节点法；返回 Zin、VSWR、S11、节点电压、元件应力
scan_matchable_range(...) 正向扫描；返回 R/X 范围与采样点
bandwidth(...) 固定元件扫频，找连续合格频段
sensitivity(...) 元件 ±5% 的最差 VSWR
voltage_stress(...) 功率下的峰值/RMS 电压电流
build_steps(...) 生成 Smith 圆图 Γ 轨迹
suggest_topologies(...) 五种拓扑可行性与排序

3.2 tools.py：MCP 工具层

把 engine.py 的能力包装成 15 个工具，统一返回：

{
  "ok": true,
  "summary": "中文摘要",
  "...": "结构化数据"
}

失败返回：

{
  "ok": false,
  "error_code": "no_solution",
  "message": "物理原因",
  "hint": "可行替代方案"
}

工具定义同时供： - MCP 服务 tools/list / tools/call； - Web 智能体 openai_tools()。

3.3 mcp_server.py：协议层

  • stdio：按行 JSON-RPC 2.0；
  • Streamable HTTP：POST /mcp + Mcp-Session-Id；
  • legacy HTTP+SSE：GET /sse + POST /messages；
  • 协议版本：2024-11-05 / 2025-03-26 / 2025-06-18；
  • 方法：initialize、tools/list、tools/call、resources/list、resources/read、prompts/list、prompts/get、ping；
  • 日志只写 stderr；
  • 支持 Content-Length 与换行分隔两种输入。

3.4 agent.py：智能体层

  • 系统提示：先算后说、单位统一、失败给替代方案、附件不当指令；
  • 工具循环最多 5 轮；
  • 工具结果截断到 16k 字符；
  • SSE 事件：status / tool_call / tool_result / design / token / done / error；
  • 设计结果生成对话内设计卡片。

3.5 llm.py：模型客户端

  • OpenAI 兼容 /chat/completions；
  • Anthropic Messages 原生适配（tool_use / tool_result）；
  • Azure OpenAI（api-key + 部署名 + api-version）；
  • 214 家服务商目录来自 models.dev，不设默认厂商/模型/Key；
  • 429/5xx 重试；
  • URL 仅允许 http/https，拒绝本机/内网/保留地址；
  • 错误信息包含 401/402/404/429 提示。

3.5.1 providers.py / providers.json：服务商目录

  • providers.json 由 release/build_providers.py 从 models.dev 生成；
  • 包含 214 家服务商的 api、api_style、chat_path、auth_header、模型 ID、文档链接；
  • 不含任何密钥，用户只能自己填写；
  • providers.py 提供 all() / find() / defaults()，供设置界面与 save_config 使用；
  • 无默认厂商/模型；UI 第一项永远是“请选择模型服务商”。

3.6 attachments.py：附件

  • 文本/代码：UTF-8 → GB18030 → GBK → Latin-1 回退；
  • PDF：pypdf；
  • DOCX：ZIP + XML 去标签；
  • XLSX：openpyxl 或 XML 回退；
  • PPTX：a:t 文本；
  • Notebook：JSON cells；
  • 图片：保存并提示文本模型不读图；
  • 限制：25MB/文件、60k 字符/附件、48k 字符/对话。

3.7 reports.py：报告

  • 输入：完整设计字典；
  • 输出：data/reports/impedance_report_*.html 或 .md；
  • HTML 含：封面 KPI、拓扑 SVG、元件表、节点法、Smith 圆图 SVG、VSWR 曲线、步骤、灵敏度、风险；
  • 使用浅色 A4 打印样式，可直接 Ctrl+P 存 PDF。

3.8 matlab_bridge.py：MATLAB 桥

  • find_matlab()：优先 R2025b；
  • find_classic_app()：定位 Impedance_Matching.exe；
  • run_matlab_design(...)：复制 mw_design.m/mw_batch_entry.m 到临时目录，matlab -batch 调用；
  • cross_check(...)：批量交叉验证；
  • launch_classic_app()：路径白名单校验后 os.startfile；
  • 安全：参数列表、shell=False、校验 MATLAB 安装目录。

3.9 web_server.py：本地 Web/API

  • 静态文件：/、/styles.css、/app.js、/smith.js；
  • API：/api/design、/api/scan、/api/evaluate、/api/stress、/api/bandwidth、/api/suggest、/api/convert、/api/upload、/api/chat（SSE）、/api/report、/api/matlab/verify、/api/matlab/open、/api/status、/api/config、/api/mcp/config；
  • 仅监听 127.0.0.1；
  • 静态路径规范化，防目录穿越；
  • 报告文件名白名单。

3.10 前端

  • index.html：五页单页应用（AI/设计/分析/耐压/关于）+ 设置模态；
  • styles.css：深色主题、响应式、打印样式；
  • smith.js：Smith 圆图类、折线图、条形图；
  • app.js：状态、API、SSE、Markdown 渲染、设计表单、扫描、耐压、设置、报告。

3.11 launcher.py 与独立 exe

  • launcher.py 是 exe 的统一入口：
  • 默认：web_server.main()，启动独立界面；
  • --mcp：mcp_server.main()，stdio；
  • --mcp --http 8790：HTTP/SSE；
  • --configure-mcp zcode|claude|codex：写入/备份客户端 MCP 配置。
  • release/build_exe.py 用 PyInstaller 打包：
  • onefile 便携版 + onedir 安装载荷（降低自解压误报、启动更快）；
  • 打包 app/impedance_mcp/web、providers.json 与 app/matlab/*.m；
  • 隐藏导入 pypdf / PIL / openpyxl；
  • 版本信息 release/version_info.txt；
  • config.py 检测 sys.frozen，用户数据写入 %LOCALAPPDATA%\ImpedanceMCP\data；
  • 输出 release/ImpedanceMCP_v4.2.0_Portable.exe 与 release/ImpedanceMCP_v4.2.0_App/。
  • installer/ImpedanceMCP.iss（Inno Setup 6）：
  • 检测 x64/VC++/ZCode，支持自定义目录、桌面/开始菜单、可选经典界面、可选 MCP 配置；
  • 输出 ImpedanceMCP_Setup_v4.2.0.exe；
  • 帮助文档安装到 {app}\docs，web_server /help/<doc> 提供内置帮助中心。

4. 数据流

4.1 设计请求

浏览器表单
  → POST /api/design
  → engine.design_network
  → 解析解 + 节点法
  → JSON（含 steps/bandwidth/sensitivity）
  → 前端渲染 KPI、Smith 圆图、表格、图表

4.2 AI 对话

浏览器输入
  → POST /api/chat（SSE）
  → agent.run_chat
  → llm.chat（带 15 个工具）
  → tools.call_tool → engine
  → 工具结果回填 LLM
  → 最终回答 + 设计卡片
  → SSE token/tool/design 事件

4.3 MCP

ZCode / Claude / Codex
  → stdio / Streamable HTTP / legacy SSE
  → mcp_server.handle
  → tools.call_tool
  → JSON-RPC result（content + structuredContent）

4.4 MATLAB 复核

前端「MATLAB 复核」
  → POST /api/matlab/verify
  → matlab_bridge.run_matlab_design
  → 临时目录 + matlab -batch
  → mw_design.m / mw_batch_entry.m
  → JSON 结果
  → 前端 toast/日志
