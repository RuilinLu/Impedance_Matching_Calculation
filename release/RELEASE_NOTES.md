## 本次修复

### 1. REST 耐压/扫描参数

- `POST /api/stress` 之前忽略 `sweep`、`sweep_points`、`frequency_span`，即使请求 `sweep=false` 仍会执行 442 次求解。现已正确传递；单点模式返回 1 次求解。
- 单点耐压的最坏电压/电流之前保持 0，导致表格显示 `0 V`。现在用标称工作点初始化最坏统计，单点结果与 KPI 正确。
- `POST /api/scan` 之前忽略 `points_budget`/`sim_points`，现在与流式扫描一致。

### 2. 三元件宽范围扫描

- 固定每维 22 点时，C3 范围从 10 扩到 1000 pF 会因低端采样变稀而让栅格区域轻微缩小。现在按电容范围的对数跨度自适应增加该维采样（最多 120），并在总点数超过 250k 时按比例收敛。
- `t / πⅠ / πⅡ` 在 C3 上限 10→30→100→1000 pF 时覆盖率单调不减；新增回归测试。

### 3. 教材翻译

- 翻译请求独立把输出上限提高到至少 16384 tokens，避免思考模型把 2k/4k 预算全部用于 reasoning 后返回空文本。
- 增加第三次短文本重试；持续失败时提示换用非思考模型。

### 4. 文档中心

- 搜索高亮不再跳过 `<code>/<pre>`，代码参考文档中的函数名、类名能被高亮并正确计数。
- 长文档搜索、模块内定位与 `doc-focus` 滚动保持正常。

### 5. 教材库与可视化

- 修复教材库侧栏“当前教材库/数据目录”长路径溢出到主区域的问题；路径在侧栏内换行。
- 三按钮操作区在窄侧栏下自动换行并均分宽度。
- 单点耐压图表显示“单点模式”提示，不再留下空白画布。
- 停止扫描提示区分“已计算”和“已绘制”点数。

### 6. MCP HTTP 稳定性

- `/mcp` 会话增加 30 分钟 TTL 与 256 个会话上限；客户端反复 `initialize` 或异常断开不会无限增长内存。
- stdio 与 HTTP 均通过 500/800 请求突发测试。

### 7. 稳定性测试

- 72 项单元测试全部通过。
- 多轮累计约 40 分钟混合 soak：8 个 HTTP worker、流式扫描、MCP stdio 批处理、MCP HTTP 并发、真实 DeepSeek Flash 对话。
- 专项：120 并发上传、300 本文档并发索引与检索、25 万点扫描、2 路 OCR 并发、500 请求 MCP stdio 突发、800 请求 MCP HTTP 并发、1200 组随机设计/复核。
- 4.4.0 → 4.4.1 覆盖安装验证配置、教材索引、路径与卸载保留数据。

## 兼容性

- 直接读取 4.3.x/4.4.0 的 `config.json`、教材 SQLite 索引、上传与报告目录。
- 旧 REST/MCP 参数保持兼容；`points_budget`/`sim_points` 为新增可选参数。
- 4.4.x 作为后续版本的兼容基线。

## 已知限制

- 更新检查需要访问 `api.github.com`；离线/代理环境回退到缓存或手动检查。
- 教材翻译质量与速度取决于用户配置的模型；思考模型可能需要更高输出预算。
- OCR 仍为 CPU 推理，扫描版教材首次 OCR 需要时间。
