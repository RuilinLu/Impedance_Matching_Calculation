## 本版重点

### 1. 教材库路径管理与可拖动面板

- 教材库新增“路径管理”：显示程序安装目录、用户数据目录、当前教材库；支持按优先级上移/下移、启用/停用、删除、新增本机文件夹。
- 内置 `TextBook` 按安装位置动态解析，移动安装目录后自动指向新位置；用户数据仍默认保存在 `%LOCALAPPDATA%\ImpedanceMatchingAI`，重装可复用。
- 搜索结果 ↔ 教材页面可左右拖动，教材页面 ↔ 原文/翻译可上下拖动，尺寸持久化。

### 2. 渐进式圆图扫描（修复“扩大范围反而缩小”）

- 仿真点数可编辑，默认 10,000，最高 250,000；旧 `steps` / `max_points` 参数仍兼容。
- 每个真实计算的元件组合逐点出现在圆图上；全部完成后绘制灰色区域。
- 灰色区域改为参数网格曲线 + 相邻曲线带状区域栅格化，不再使用凸包；电容按对数采样。实测 C2 上限 10 → 30 → 100 → 1000 pF 时覆盖率单调增加。
- 扫描期间可停止；显示已计算/总数、有效点数、覆盖率和耗时。

### 3. 耐压分析可验证

- 新增频率 ±% × 功率 10%–100% 二维扫描，每个组合执行一次真实节点求解。
- 显示求解次数、耗时、最坏频率/功率/元件；元件表峰值取最坏值，悬停显示标称值。
- 单点计算仍然很快（最多三个节点的线性求解），但界面会明确显示“1 次求解”，不再像缓存结果。

### 4. 附件上传进度

- 粘贴截图/文件后立即显示附件条目，按 2 MB 分块上传，显示真实百分比与进度条。
- 上传未完成时禁止发送；主聊天与浮动助手共用同一套上传逻辑。

### 5. 聊天显示开关

- 主聊天与浮动助手都增加“思考”“引用”开关；默认折叠思维链路与参考来源。
- 每条回答的思考过程和参考来源可单独展开；回答结束后参考文献统一收在末尾。
- 设置 → 界面可修改默认展开状态。

### 6. 启动更新检查

- 启动约 2 秒后读取 GitHub 最新 Release，按语义版本比较；已配置模型时再用当前模型审查版本说明与兼容性（模型只做摘要，不决定版本）。
- 支持“稍后”“跳过此版本”“打开发布页”“下载并安装”；下载显示百分比，完成后启动安装程序。
- 6 小时缓存，离线时回退到上次结果。

### 7. 卸载数据选项

- 卸载时询问是否保留个人数据：保留 API Key、界面设置、教材索引、上传/报告、翻译缓存和搜索路径；彻底删除时清理用户目录与缓存。
- 保留模式下，程序目录 `TextBook` 中的文件会先复制到用户数据目录，重装后仍可检索。

### 8. 兼容性

- 直接读取 4.3.x 的 `config.json`、教材 SQLite 索引、上传与报告目录；新增配置项默认值合并，不覆盖旧字段。
- 安装目录变化后教材索引自动重建；4.4.0 作为 4.5.0 等后续版本的兼容基线。
- 旧 API 字段与 MCP 工具保持可用；20 个 MCP 工具数量不变。

## 升级说明

直接运行 4.4.0 安装程序覆盖安装即可。安装程序会保留 `%LOCALAPPDATA%\ImpedanceMatchingAI` 下的配置、API Key、教材索引与上传文件；旧版 `TextBook` 目录如仍在原安装位置，可手动移动到新安装目录或通过“教材库 → 路径管理”添加。

## 已知限制

- 更新检查需要访问 `api.github.com`；企业代理或离线环境会回退到缓存/手动检查。
- 分块上传单文件上限 60 MB（聊天附件）与 120 MB（教材库）；超大文件建议先放入教材搜索目录后重建索引。
- OCR 仍为 CPU 推理，扫描版教材首次 OCR 需要时间。
